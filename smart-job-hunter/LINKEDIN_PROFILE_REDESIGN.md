## 10. RECRUITER PSYCHOLOGY — WHAT MAKES THEM CLICK

### Why Recruiters Open a Profile (in order):
1. **Headline matches their search query** — "Java" + "Spring Boot" + "Backend" = instant hit
2. **Current activity** — "Building [X]" signals you're active, not dormant
3. **Specific project names** — "JobFlow AI" is memorable vs "personal project"
4. **Numbers** — "500+ records", "73 jobs scraped", "15+ endpoints" = credibility
5. **AI/Modern stack mentions** — Shows you're current, not stuck in legacy

### What Makes Them Reach Out:
- About section that reads like a human wrote it (not ChatGPT filler)
- Projects with clear outcomes, not just tech stack lists
- Evidence you can ship end-to-end (not just "contributed to")
- GitHub activity or live demos (proof over claims)

### Red Flags to Avoid:
- "Passionate learner eager to grow" — every fresher says this
- "Aspiring software engineer" — you ARE an engineer, not aspiring
- Listing courses/certifications before projects
- "Proficient in DSA" without systems you've built
- Generic buzzwords: "innovative", "dynamic", "self-motivated"
- The green "Open to Work" badge (signals desperation to some recruiters — use the recruiter-only setting instead)

### Your Differentiators (Use These):
1. **You build entire products solo** — most juniors only do fragments
2. **You integrate AI into real systems** — not just API calls in a notebook
3. **You automate workflows** — browser automation, scrapers, pipelines
4. **You've built across domains** — FinTech, HealthTech, Social, Career Tech
5. **You think in systems** — ATS scoring, quality gates, pipeline management
